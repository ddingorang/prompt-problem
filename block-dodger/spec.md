# Block Dodger: 아이템 효과 추가

## 문제 설명

제공된 스켈레톤 코드는 좌우 방향키로 초록색 바를 움직여 빨간 블록을 피하는 간단한 게임입니다.

게임에 새로운 아이템 기믹을 추가하세요. 플레이어가 아이템을 먹으면 바의 길이가 바뀌어야 합니다.

## 구현할 기능

### 1. 초록 아이템

- 일정 시간 간격으로 초록색 아이템을 생성하세요.
- 플레이어 바가 초록 아이템과 닿으면 아이템을 제거하세요.
- 초록 아이템을 먹을 때마다 플레이어 바의 너비를 늘리세요.

### 2. 노란 아이템

- 일정 시간 간격으로 노란색 아이템을 생성하세요.
- 플레이어 바가 노란 아이템과 닿으면 아이템을 제거하세요.
- 노란 아이템을 먹을 때마다 플레이어 바의 너비를 줄이세요.

### 3. 공통 동작

- 아이템은 화면 위에서 생성되어 아래로 내려와야 합니다.
- 아이템이 화면 아래로 벗어나면 자동으로 제거하세요.
- 바의 너비가 변해도 플레이어가 캔버스 밖으로 나가지 않도록 처리하세요.
- 바의 너비가 지나치게 작아지지 않도록 최소 너비를 정하세요.

## 완료 조건

- 빨간 블록, 초록 아이템, 노란 아이템을 화면에서 구분할 수 있다.
- 초록 아이템을 먹으면 바가 눈에 띄게 길어진다.
- 노란 아이템을 먹으면 바가 눈에 띄게 짧아진다.
- 아이템을 먹은 뒤에도 충돌 판정과 좌우 이동이 정상 동작한다.
- 기존 게임 오버 및 점수 기능이 유지된다.

## 참고

- 아이템의 생성 주기, 낙하 속도, 바가 변하는 크기는 자유롭게 정해도 됩니다.
- 구현이 끝나면 `src/main/html/sample-game.html` 파일만 실행해도 게임이 동작해야 합니다.
