# 리뷰 단어 빈도 리포트

## 문제 상황

상품 리뷰에서 자주 등장하는 단어를 뽑아 관리자 화면에 보여주려 한다.

`report.py`의 `top_words()` 함수는 리뷰 텍스트를 받아 가장 자주 등장한 단어 상위 3개를
`"단어:횟수"` 형식의 문자열 리스트로 반환해야 한다. 현재는 빈 리스트만 반환한다.

```text
입력: "Good good service. Fast delivery, good price!"
현재 결과: []
기대 결과: ["good:3", "delivery:1", "fast:1"]
```

---

## 규칙

1. 단어는 공백으로 구분한다.
2. 대소문자는 구분하지 않으며, 결과의 단어는 소문자로 표기한다.
3. 단어 앞뒤에 붙은 문장부호(`.` `,` `!` `?`)는 단어의 일부가 아니다.
4. 빈도 내림차순으로 정렬하고, 빈도가 같으면 사전순으로 앞선 단어를 우선한다.
5. 서로 다른 단어가 3개 미만이면 있는 만큼만 반환한다.

---

## 수정 제한

* `report.py`만 수정한다.
* `top_words()` 함수의 이름, 매개변수와 반환 타입을 변경하지 않는다.
* 새로운 파일을 추가하거나 기존 파일을 삭제하지 않는다.
* 외부 라이브러리를 추가하지 않는다. 표준 라이브러리는 사용할 수 있다.
