# 게임 인벤토리 병합

## 문제 상황

RPG 게임에서 캐릭터가 사냥을 마치고 마을로 돌아왔을 때, 새로 획득한 전리품들을 기존 인벤토리에 병합하는 기능에 버그가 발생했습니다.

`inventory.py`의 `merge_items()` 함수는 기존 인벤토리와 새로 획득한 아이템 목록을 받아 병합된 인벤토리를 반환해야 합니다. 현재 구현은 기존 아이템을 덮어쓰거나 수량이 제대로 더해지지 않으며, 아이템이 파괴(수량 0 이하)되었을 때 처리하는 로직이 누락되어 있습니다.

```text
입력: current={"hp_potion": 3, "sword": 1}, new=[{"name": "hp_potion", "quantity": 2}, {"name": "shield", "quantity": 1}]
현재 결과: {"hp_potion": 2, "sword": 1, "shield": 1}
기대 결과: {"hp_potion": 5, "sword": 1, "shield": 1}
```

---

## 규칙

1. `current_inventory`는 `{"아이템명": 수량, ...}` 형태의 딕셔너리입니다.
2. `new_items`는 새로 획득한 아이템 목록으로 `[{"name": "아이템명", "quantity": 수량}, ...]` 형태의 리스트입니다.
3. 새로 획득한 아이템이 기존에 있다면 수량을 더하고, 없다면 새로 추가합니다.
4. 만약 아이템의 총 수량이 `0` 이하가 된다면, 인벤토리 딕셔너리에서 해당 아이템을 완전히 삭제해야 합니다.
5. `new_items`가 비어있을 수도 있으며, 이때는 기존 인벤토리를 그대로 반환(혹은 유지)해야 합니다.

---

## 기대 결과

| 기존 인벤토리 | 획득한 아이템 | 기대 결과 |
| --- | --- | --- |
| `{"potion": 5, "sword": 1}` | `[{"name": "potion", "quantity": 5}, {"name": "sword", "quantity": -1}]` | `{"potion": 10}` |
| `{"apple": 2}` | `[{"name": "banana", "quantity": 3}]` | `{"apple": 2, "banana": 3}` |
| `{}` | `[{"name": "gem", "quantity": 1}]` | `{"gem": 1}` |
| `{"gold": 100}` | `[]` | `{"gold": 100}` |

---

## 수정 제한

* `inventory.py`만 수정합니다.
* `merge_items()` 함수의 이름, 매개변수와 반환 타입을 변경하지 않습니다.
* 새로운 파일을 추가하거나 기존 파일을 삭제하지 않습니다.
* 외부 라이브러리를 추가하지 않습니다.
