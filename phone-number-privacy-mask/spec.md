# 전화번호 개인정보 보호 처리

## 문제 상황

고객 정보 화면에 사용자의 전화번호가 그대로 노출되고 있다.

현재 `PhoneNumberFormatter.maskPhoneNumber()` 메서드는 전달받은 전화번호를 별도의 처리 없이 그대로 반환한다.

```text
입력: 010-1234-5678
현재 결과: 010-1234-5678
````

개인정보 보호를 위해 전화번호 일부를 `*`로 가려서 표시해야 한다.

입력되는 전화번호는 하이픈으로 구분되어 있으며, 전화번호 종류에 따라 각 번호 구간의 길이가 다를 수 있다.

제공된 코드와 아래 예시를 확인하여 전화번호가 지정된 형식으로 반환되도록 수정한다.

---

## 기대 결과

| 입력              | 기대 결과           |
| --------------- | --------------- |
| `02-123-4567`   | `02-***-4567`   |
| `02-1234-5678`  | `02-****-5678`  |
| `010-1234-5678` | `010-****-5678` |
| `070-9876-5432` | `070-****-5432` |

전화번호 형식이 달라지더라도 위 예시에서 확인할 수 있는 동일한 규칙을 적용해야 한다.

---

## 요구사항

1. 전화번호에서 개인정보 보호가 필요한 번호 구간을 `*`로 변경한다.
2. 가려지지 않는 번호와 하이픈을 포함한 기존 표시 형식은 유지한다.
3. 마스킹에 사용하는 `*`의 개수는 가려지는 번호 구간의 길이에 맞춰야 한다.
4. 전화번호 종류에 따라 각 번호 구간의 길이가 다를 수 있음을 고려한다.
5. 마스킹된 새로운 문자열을 반환한다.

---

## 수정 제한

* `PhoneNumberFormatter.java`만 수정한다.
* 기존 클래스 이름을 변경하지 않는다.
* `maskPhoneNumber()` 메서드의 이름, 매개변수와 반환 타입을 변경하지 않는다.
* 새로운 파일을 추가하거나 기존 파일을 삭제하지 않는다.
* 외부 라이브러리를 추가하지 않는다.
* 요구사항에 없는 전화번호 유효성 검사나 형식 변환 기능은 추가하지 않는다.
* 이번 문제에서는 하이픈으로 구분된 전화번호만 처리한다.
