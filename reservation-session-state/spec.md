# 예약 세션 간 좌석 선택 정보 공유 오류

## 문제 상황

좌석 예약 프로그램은 예약을 시작할 때마다 새로운 `ReservationSession` 객체를 생성한다.

각 예약 세션에서는 좌석을 선택하거나 선택을 해제할 수 있으며, 선택된 좌석을 기준으로 총 예약 금액을 계산한다.

하나의 예약 세션만 사용하는 경우에는 좌석 선택, 선택 해제, 금액 계산이 정상적으로 동작한다.

그러나 여러 예약 세션을 생성하면 한 세션에서 선택한 좌석이 다른 세션에서도 조회되는 문제가 발생한다.

또한 다른 세션에서 좌석을 선택 해제하면 기존 세션의 선택 목록과 총 예약 금액까지 변경된다.

제공된 코드를 확인하여 예약 세션 간 좌석 선택 정보가 공유되는 오류를 수정한다.

---

## 현재 동작

다음과 같이 두 개의 예약 세션을 생성한다.

```java
ReservationSession firstSession = new ReservationSession();
ReservationSession secondSession = new ReservationSession();

Seat seat = new Seat("A-1", Seat.Grade.VIP);

firstSession.select(seat);
````

현재 결과:

```text
firstSession 선택 좌석 수: 1
secondSession 선택 좌석 수: 1

firstSession 총 금액: 150000
secondSession 총 금액: 150000
```

첫 번째 세션에서만 좌석을 선택했지만 두 번째 세션에도 같은 좌석과 금액이 반영된다.

또한 다음과 같이 두 번째 세션에서 좌석을 선택 해제하면:

```java
secondSession.deselect(seat);
```

첫 번째 세션의 선택 정보까지 제거된다.

---

## 기대 동작

* 새로운 예약 세션은 빈 좌석 선택 목록으로 시작해야 한다.
* 각 예약 세션은 선택한 좌석을 독립적으로 관리해야 한다.
* 한 예약 세션의 좌석 선택과 선택 해제가 다른 세션에 영향을 주지 않아야 한다.
* 각 예약 세션의 총 금액은 해당 세션에서 선택한 좌석만 기준으로 계산되어야 한다.
* 좌석 등급별 가격은 모든 예약 세션에 동일하게 적용되어야 한다.

예상 결과:

```text
firstSession 선택 좌석 수: 1
secondSession 선택 좌석 수: 0

firstSession 총 금액: 150000
secondSession 총 금액: 0
```

---

## 요구사항

1. 예약 세션마다 선택한 좌석을 독립적으로 관리한다.
2. 새로운 예약 세션은 빈 선택 목록으로 시작한다.
3. 한 예약 세션의 좌석 선택 및 선택 해제가 다른 예약 세션의 상태에 영향을 주지 않도록 한다.
4. 각 예약 세션의 총 금액은 해당 세션에서 선택한 좌석만 기준으로 계산한다.
5. 모든 예약 세션에서 공통으로 사용하는 좌석 등급별 가격 정보는 기존 방식으로 유지한다.
6. 기존 좌석 선택, 선택 해제 및 금액 계산 동작을 유지한다.

---

## 수정 제한

* `ReservationSession.java`만 수정한다.
* `Seat.java`는 수정하지 않는다.
* 기존 클래스 이름과 공개 메서드의 이름, 매개변수 및 반환 타입을 변경하지 않는다.
* 새로운 파일을 추가하거나 기존 파일을 삭제하지 않는다.
* 외부 라이브러리를 추가하지 않는다.
* 요구사항에 없는 기능은 추가하지 않는다.
